# Entrega

## Técnicas Aplicadas

- Few-Shot: Definir exemplos de entrada e saída para o modelo aprender com poucos dados. Foi utilizado no system_promt, na seção Exemplos.
- Role prompting: Definir a persona a ser tomada pelo modelo quando executar a tarefa. Foi utilizado no início do system_promt, definindo a persona como assistente que ajuda a transformar relatos de bugs de usuários.
